# OpenGaokao 算法说明

## 录取概率模型

### 核心公式

```
P = 50 + 50 × (1 - e^(-2 × Δrank / pred_rank))
```

其中：
- `Δrank = predicted_rank - user_rank`（正值表示考生位次优于预测位次）
- `predicted_rank` 为近3年录取位次的中位数，经趋势调整
- 当 `user_rank < predicted_rank`（考生更好）：P ∈ (50, 99.5]
- 当 `user_rank > predicted_rank`（考生更差）：P ∈ [1, 50)

### 多年度加权

3 年历史数据按年份加权（最近年份权重最高）：
- 最近一年：50%
- 中间一年：30%  
- 最远一年：20%

### 趋势调整

趋势钳制在 ±30%，防止单一年的异常波动过度影响预测。

### 置信度评估

- **high**: ≥3 年数据
- **medium**: 2 年数据
- **low**: 1 年数据
- **none**: 无数据

新旧高考转换时，置信度自动降一级（因为科类不可比）。

## 冲稳保分层

| 档位 | 概率区间 | 策略 |
|------|---------|------|
| 冲 | < 35% | 冲击更好学校 |
| 稳 | [35%, 85%) | 稳妥匹配 |
| 保 | ≥ 85% | 确保录取 |
| 垫 | 50-85%（当稳不足时） | 保底替补 |

## 漏斗排除（四步顺序过滤）

```
全量候选
   → Step 1: 选科排除（硬性过滤，选科不匹配直接排除）
   → Step 2: 学科偏好排除（弱项学科对应专业类排除）
   → Step 3: 体检排除（色盲/色弱/视力等身体条件限制）
   → Step 4: 兴趣排除（项目自编 RIASEC 风格兴趣代码不匹配时建议排除）
   → 剩余候选
```

## 四维偏好问卷（非心理诊断）

四类题面均由本项目自编，仅用于提供方向性偏好信号：

### 1. 项目自编大五维度问卷
- 50 题，5 维度
- 开放性/尽责性/外向性/宜人性/神经质
- 含反向计分题

### 2. 项目自编 RIASEC 风格兴趣偏好问卷
- 76 题迫选配对
- 6 维度：现实型/研究型/艺术型/社会型/企业型/常规型

### 3. 项目自编学科自我评价问卷
- 15 题
- 语文/数学/英语 3 维度

### 4. 项目自编职业价值偏好问卷
- 20 题，10 维度
- 稳定性/收入/创造性/助人/平衡/领导/自主/地点/学习/成就

### 理论与授权边界

- “大五”和 “RIASEC”只表示本项目借用的理论维度名称；现有题面和计分规则不是 BFI/BFI-2、Holland SDS 等标准化工具，也不声称与这些工具等效。
- 学科自我评价和职业价值偏好题目不是 Bandura 或 Schwartz 的授权量表、翻译版或改编版。
- 当前问卷没有常模、信度、效度或心理测量学验证证据，不用于心理诊断、职业诊断或替代专业咨询。
- 由问卷生成的专业方向仅作探索线索，必须与成绩、位次、选科要求、招生章程和个人核验共同使用。

## 风险模型

### 滑档风险
- 检查保底志愿数量（≥3 所且概率 ≥90%）

### 高分低就风险
- 平均保底位次与考生位次差距
- 差距超过阈值（本科段 30,000 名/专科段 50,000 名）触发

### 退档风险
- 检查是否服从调剂
- 体检限制未过时标记高风险

## 数据来源

- **score_line_{year}**: 各年投档线表
- **v_enroll_detail**: 录取明细视图（含科类/批次）
- **enroll_plan_{year}**: 当年招生计划
- **school_info**: 院校信息（985/211/层次/地点）
- **major_catalog**: 专业目录
- **major_revocation_stats**: 专业撤销统计
- **score_distribution**: 一分一段表
